Mayfreia Sachiara Althafunnisa

## Deskripsi singkat
Penyimpanan digital berbasis cloud yang digunakan untuk menyimpan berkas proyek, source code, dan seluruh riwayat perubahannya.

## Tujuan
Mengamankan data, mencatat riwayat perubahan, memfasilitasi kolaborasi tim, mengelola tugas proyek, dan menjadi portofolio digital.

---

### <ins>Rangkuman materi yang disampaikan selama workshop</ins>
Materinya mencakup cara bikin aplikasi dengan bantuan AI, dan cara mencatat serta mengelola perubahannya pakai Git dan GitHub. Di bagian AI, pesan utamanya sederhana: makin jelas konteks yang kita kasih, makin bagus hasilnya, jadi prompt sebaiknya punya peran, tugas, konteks, dan format yang jelas, bukan cuma satu kalimat pendek. Di bagian Git, berfungsi sebagai pencatat perubahan file di komputer sendiri, sedangkan GitHub adalah tempat menyimpannya secara online supaya bisa dikerjakan bareng.

### <ins>Poin-poin penting atau pengetahuan baru yang dipelajari saat workshop</ins>
Poin pentingnya adalah saat bertanya ke AI, kalau konteksnya jelas maka AI memberikan hasil yang jelas juga. Pengetahuan baru yang dipelajari adalah cara memakai Git dan GitHub sebagai tempat penyimpanan secara online.
